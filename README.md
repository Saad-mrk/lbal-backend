# Lbal API 🚀

Backend RESTful API for the **Lbal** project, built with **ASP.NET Core Web API**.

## 🛠️ Tech Stack
- ASP.NET Core Web API (.NET 8)
- Entity Framework Core
- SQL Server
- JWT Authentication


## 📁 Project Structure
- Controllers/ → API Endpoints
- Services/    → Business Logic
- Models/      → Data Models
- Data/        → Database Context
